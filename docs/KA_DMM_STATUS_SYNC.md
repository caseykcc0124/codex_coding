## 已實作並驗證

可運行流程為 PDF → 官方 DoclingDocument → 原生 JSON、圖片資產與版本化 Manifest → 新程序重載 → 唯讀零修訂視圖 → chunks → 本地檢索與可核對來源引用。

DoclingDocument 是切片唯一內容母本。流程不經過 DocumentStructure，也沒有建立第二套通用文件樹。切塊重用既有純算法，預設 1500 字元、100 字元重疊；表格依列切分並重複表頭。

實測來源是一份兩頁合成 PDF，包含標題、段落與 3×3 表格。解析結果保留原生節點、頁碼及 bbox，保存兩張頁面圖片並產生七個 chunks。圖片資產仍在，唯讀 Markdown 視圖使用圖片佔位符。

驗證環境為 docling-slim 2.137.0、docling-core 2.101.1、DocLang 0.7.3；原生文件 Schema 為 1.10.0。套件版號、文件 Schema 與 Manifest 版號分別保存。

引用綁定來源與快照 SHA、文件版本、原生節點、文字範圍或表格結構，以及頁碼和 bbox。来源或已載入內容改變時拒絕沿用引用，不宣稱已完成跨版本 remap。
